นโยบายการคืนเงิน

ยกเลิกก่อนเริ่มเรียน: นักเรียนได้เงินคืน 100% โดยอาจหักเฉพาะค่าธรรมเนียม gateway ตามที่ระบบกำหนด
ยกเลิกกลางคัน: ระบบคำนวณคืนเงินตามจำนวนชั่วโมงที่ยังไม่ได้เรียนจริง
Refund Transaction: เงินคืนจะถูกบันทึกลง Transaction_Log และเข้ากระเป๋า Wallet ทันที

สิทธิ์ของนักเรียนในระบบ Wallet

ฝากเงินได้: เติมเงินเข้า Wallet เพื่อจ่ายค่าเรียน
ถอนเงินได้: ถอนยอดคงเหลือที่ยังไม่ได้ใช้กลับออกจากระบบ
ดูประวัติได้: ตรวจสอบรายการเงินเข้า-ออกย้อนหลังได้ตลอดเวลา
หน้านี้เป็น Frontend สำหรับฝั่งนักเรียนก่อน โดยสามารถนำไปเชื่อมกับตาราง Wallet และ Transaction_Log รวมถึง API สำหรับ deposit / refund / payment / withdrawal ได้ภายหลัง
